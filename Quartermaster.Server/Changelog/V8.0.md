### UU-Assistent

Der neue UU-Assistent unter "Vorstandsarbeit" hilft beim Sammeln von Unterstützungsunterschriften für Wahlvorschläge. Für jede Sammlung, etwa die Landesliste oder eine Direktkandidatur, werden nur Zahlen erfasst, keine Formulare und keine Daten der Unterzeichnenden: wie viele Formulare aus welcher Gemeinde eingegangen sind, welche an welche Bestätigungsstelle verschickt wurden und wie viele bestätigt oder abgelehnt zurückkamen. Die Anschreiben an die Bestätigungsstellen entstehen aus einer PDF-Vorlage, Samtgemeinden werden aus dem amtlichen Gemeindeverzeichnis erkannt, und Mitglieder sehen auf der Startseite den Fortschritt und können das Formular herunterladen.
